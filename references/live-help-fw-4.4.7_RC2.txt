Usage:
internet -W n -M n [-<command> <parameter> | ... ]
  -h: Usage Menu

  -t n: Always-on/Idle Timeout
     n= -1: Always-on, 1 ~ 999: Idle time for offline (default 180 seconds)
  -i <ip address>: PPP IP Negotiation Method

  -w <ip address>: Assign WAN IP
     <ip address>= aaa.bbb.ccc.ddd: IP for WAN port
  -n <netmask>: Assign WAN netmask
     <netmask>= 255.255.255.xxx: netmask for WAN port
  -g <gateway>: Assign WAN Gateway IP

  -A <idx>: Set to Always On mode, and <idx> as backup WAN#
  -B <mode>: Set to Backup mode;
     <mode> 0: When any WAN disconnect; 1: When all WAN disconnect.
  -V : View Internet Access Profile
  -R n: Set (PPP mode) WAN Connection Detection Echo Interval (3-60) secondes
  -H n: Set (PPP mode) WAN Connection Detection Max Echo Failure Count (3-60)
